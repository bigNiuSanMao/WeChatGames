# WeChatGames（家庭游戏大厅）

一个无广告的微信小游戏合集工程，首页是“游戏大厅”，后续可持续添加更多小游戏入口。

当前已内置第一个可玩游戏：《植物守卫战》。

## 特性

- 完全无广告：不接入任何广告 SDK
- 多入口大厅：新增游戏只需要增加配置 + 新场景模块
- 《植物守卫战》玩法：放置植物、防守怪物波次
- 素材本地化：不依赖外链，启动时预加载本地图片资源

## 运行方式（微信开发者工具）

1. 打开微信开发者工具
2. 选择“小游戏”项目
3. 导入目录：

```
/Users/coinbene_wlt/Documents/小程序游戏
```

4. 如有自己的小游戏 AppID，可在 `project.config.json` 中替换 `appid`

## 游戏说明：《植物守卫战》

- 基础资源：阳光（会自动增长，阳光树也会产出）
- 植物（当前 5 种）：
  - 阳光树：持续产出阳光
  - 豆豆花：发射子弹
  - 坚果藤：高生命值阻挡
  - 寒冰草：子弹带减速
  - 爆爆果：触发范围爆炸
- 怪物（当前 4 种）：
  - 普通怪物
  - 快速怪物
  - 护甲怪物
  - 重型怪物
