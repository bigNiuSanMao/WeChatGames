# WeChatGames（沃沃避难所）

一个无广告的微信小游戏合集工程，首页是“沃沃避难所”，后续可持续添加更多小游戏入口。

当前已内置第一个可玩游戏：《沃沃避难所》。

## 特性

- 完全无广告：不接入任何广告 SDK
- 多入口大厅：新增游戏只需要增加配置 + 新场景模块
- 《沃沃避难所》玩法：放置守卫单位、防守怪物波次
- 素材本地化：不依赖外链，启动时预加载本地图片资源
- 平板适配：针对横屏平板调整了侧边栏宽度、卡片高度与棋盘比例

## 运行方式（微信开发者工具）

1. 打开微信开发者工具
2. 选择“小游戏”项目
3. 导入目录：

```
/Users/coinbene_wlt/Documents/小程序游戏
```

4. 如有自己的小游戏 AppID，可在 `project.config.json` 中替换 `appid`

## 游戏说明：《沃沃避难所》

- 基础资源：能量（会自动增长，补给花仓也会产出）
- 植物（当前 5 种）：
  - 补给花仓：持续产出能量
  - 沃沃哨卫：发射子弹
  - 避难壁垒：高生命值阻挡
  - 霜冻岗哨：子弹带减速
  - 轰鸣果仓：触发范围爆炸
- 怪物（当前 4 种）：
  - 游荡者
  - 疾行者
  - 铁甲者
  - 重装者
